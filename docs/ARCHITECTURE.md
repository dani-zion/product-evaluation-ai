# Project architecture

## Front-end
Let`s use the following libraries:
- TypeScript: Main development language\
- Next.js: Framework for UI and API managment
- React.js: UI components
- Biome: Code validation/formatting
- TailwindCSS: Styling
- Date-FNS: Time manipulation
- Shadcn: Design system - base componetization
- React Query: Creation and management of queries to read and update data from API

## Back-end
- TypeScript: Main development language\
- Next.js: Framework for API creation and managment
- bcrypt: Password hashing (the salt is generated by bcrypt and stored inside the hash)
- Mastra.ai: Internal agents customization
- tRPC: Typed endpoints used by the front-end
- REST (Next.js route handlers under `/api/v1/...`): Public endpoints for external clients (e.g. N8N)
- tRPC procedures and REST routes call the same service layer, so business logic is never duplicated

## Database
- Supabase: PostgreSQL

## Infrastructure
- Vercel: Client and server hosting

## Automation
- N8N: Automated workflows
